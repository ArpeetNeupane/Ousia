# 🧩 Contributing to Ousia

First off, thank you for taking the time to contribute! ❤️  
This project is focused on creating a safer social media space using sentiment analysis, especially for underage users.

---

## 🧠 Before You Start

> ⚠️ Please read and respect our [Code of Conduct](./CODE_OF_CONDUCT.md).

This project is currently maintained by a solo developer. While contributions are welcome, features and ideas will be reviewed carefully to ensure they align with the project’s core goals of **privacy, safety, and AI-driven content moderation**.

---

## 🛠️ How to Contribute

### 🐞 Report Bugs
1. Open an [issue](https://github.com/ArpeetNeupane/ousia/issues)
2. Use the **Bug Report** template
3. Include:
   - Clear steps to reproduce
   - Expected behavior
   - Screenshots/logs if available

### 💡 Suggest Features
1. Open an issue with the **Feature Request** template
2. Describe the motivation behind your idea
3. Try to keep it in scope of:
   - Social safety
   - AI moderation
   - Community-friendly interactions
